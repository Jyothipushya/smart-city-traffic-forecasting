
# 🚦 Smart City Traffic Forecasting

## 📌 Overview
We are working with the government to transform various cities into smart cities. One of the major problems faced by the government is traffic management. This project aims to understand the traffic patterns of four junctions of the city and forecast traffic volume to help in infrastructure planning for the future.

---

## 📋 Problem Statement
Traffic patterns on holidays, as well as on various other occasions during the year, differ from normal working days. The government wants to implement a robust traffic system by being prepared for traffic peaks. This project analyzes and forecasts traffic patterns at 4 city junctions to provide input on infrastructure planning.

---

## 📂 Dataset
- **Records:** 48,120 rows
- **Columns:** DateTime, Junction, Vehicles, ID
- **Period:** November 2015 to June 2017
- **Junctions:** 4
